->Bomberman Remeastered is remeastered version of classical Bomberman games with several gameplay updates and graphical improvements. 

->To play Bomberman Remeastered JVM is necessary.

->Running the main class is enough for start playing.

->You can freely change and use the game files and assets as you desire.

->Assets are made in ASprite, there is no extra prog used for development.

Gameplay:

-> Z to drop bomb 

-> You have 3 life, monster touches and bomb explosions kill you and take 1 life.

-> Map randomly generating each game.

-> There are 5 skills you can aquire by destroying breakable blocks. 

-> Skills helps you to deal with monsters

-> The goal is finding the door and getting in before be eaten by monsters.

-> DO NOT EXPLODE THE DOOR. Scary serial killer monsters are waiting to punish you if you do...(Try it)

-> Have fun
